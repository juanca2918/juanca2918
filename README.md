## What I do

I build **production Odoo 18 modules** for real businesses — ERP customization,
Point of Sale extensions, access control and Colombian electronic invoicing (DIAN).

Most of this code runs in live client deployments: retail stores, POS terminals
with hardware integrations, and multi-company accounting setups.

- 🏢 Odoo module development (Community Edition 17 / 18)
- 🛒 Point of Sale customization — OWL components, hardware integration
- 🇨🇴 Colombian electronic invoicing (DIAN) — FE / NE
- 🐳 Deployment with Docker, PostgreSQL and Nginx
- 🔌 Hardware bridges: Web Serial API, network printing, serial scales

## Published Odoo modules

| Module | What it solves | Stack |
|---|---|---|
| [**prevent_zero_sales**](https://github.com/juanca2918/prevent_zero_sales) | Blocks confirming sales orders and invoices with zero/negative prices, duplicate lines or insufficient stock. Configurable per company and product type. | Python · Odoo 18 · OWL |
| [**pos_moresco_direct**](https://github.com/juanca2918/pos_moresco_direct) | Connects a Moresco HY-918 scale to Odoo POS **directly from the browser** via Web Serial API — no IoT Box required. Includes full keyboard-only POS navigation. | JavaScript · Web Serial API · OWL |
| [**menu_control_visibilidad**](https://github.com/juanca2918/menu_control_visibilidad) | Per-user menu visibility and CRUD permissions without touching security groups. Patches the view arch in memory at `get_views()`. | Python · Odoo 18 |
| [**pos_stock_policies**](https://github.com/juanca2918/pos_stock_policies) | Stock availability policies enforced inside the Point of Sale session. | Python · JavaScript · Odoo 18 |
